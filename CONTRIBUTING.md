# Contributing

This repository owns the public profile and its safe role/stack banner. Keep claims factual and links readable without private access. Do not publish resume contacts, employer details, private architecture or unverified achievements.

Run `make lint` from this exact Git root using the documented prepared lint tools. Full acceptance is manual; `make coverage` reports `notApplicable` for this documentation-only repository. PRs identify the change, compatibility, actual checks and recovery; publication and repository settings need the current task permission.

Use [development](docs/development.md), [versioning](docs/versioning.md) and
[release procedure](docs/releases.md) for checked source bundles.
