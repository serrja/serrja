# Public personal profile

Read the [selected baseRules](https://github.com/serrja/baseRules/tree/730418d3cc480b4f05b88b4c8275296c4845a75a)
engineering/documentation pages, then this repo's CONTRIBUTING.md. rules.lock.json records the
reviewed full source; links are an explicit reading order, not automatic loading or new grants.

Keep the profile concise and factual. The banner carries useful role/stack text; duplicate key
information in accessible README text and descriptive alt text. Do not restore a decorative logo.

metrics. Keep private code access explicit. Run the pinned documentation check and CI for the
exact proposed tree. This repository owns no application runtime or account-wide settings.
